Использование `sx` Prop в Material UI

1.	Установите необходимые зависимости
Убедитесь, что у вас установлены необходимые пакеты для Material UI: 
npm install @mui/material @emotion/react @emotion/styled

2.	Создайте новый файл компонента

Создайте файл `MyComponent.js` в папке `src` вашего проекта. Этот файл будет содержать компонент, который вы будете стилизовать с помощью `sx` prop.

3.	Импортируйте необходимые модули

В файле `MyComponent.js` импортируйте компоненты Material UI, которые вы будете использовать: `Box` и `Button`.

4.	Создайте компонент

Создайте функциональный компонент, который будет возвращать JSX с компонентами Material UI. Используйте `sx` prop для стилизации этих компонентов:

-	Box: создайте контейнер с использованием компонента `Box` и добавьте к нему `sx` prop для стилизации отступов и фона.

-	Button: создайте кнопку с использованием компонента `Button` и добавьте к ней `sx` prop для стилизации цвета текста и фона.

5.	Стилизация

Box: установите фон с цветом `lightblue`, добавьте внутренние отступы `16px` и установите внешние отступы `8px`.

Button: установите цвет текста `white`, фон `blue`, добавьте внутренние отступы `12px` и измените шрифт на `bold`. 6.	Создайте основной файл приложения

В файле `App.js` импортируйте созданный компонент `MyComponent` и используйте его внутри компонента `App`.

7.	Запустите приложение

Убедитесь, что ваше приложение работает без ошибок и отображает компоненты с заданными стилями.

8.	Проверка результата

Проверьте стили: Убедитесь, что компоненты `Box` и `Button` отображаются со стилями, заданными с помощью `sx` prop.

Измените стили: Попробуйте изменить значения в `sx` prop и проверьте, как эти изменения отражаются в вашем приложении. Это поможет убедиться, что `sx` prop работает корректно и позволяет легко управлять стилями компонентов.
